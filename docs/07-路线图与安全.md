# 路线图与安全合规

## 1. 迭代路线图

| 阶段 | 范围 | 验收 |
|---|---|---|
| **v0.1 MVP（本次）** | 文档全套；后端全模块（零依赖可跑）；Flutter 全页面源码；Mock/GPX 导入；高驰 OAuth 链路；计划引擎 | 冒烟测试全绿；README 可复现 |
| v0.2 | Flutter 真机联调与 UI 打磨；TCX/FIT 导入；ICS 日历导出 | iOS/Android 真机跑通 |
| v0.3 | 佳明 Health API、华为 Health Kit 正式接入；跑鞋管理 | 沙箱环境拉数成功 |
| v0.4 | 后端生产化：Express/Fastify + PostgreSQL + Redis 队列；Docker 部署；监控告警 | 压测 200 QPS |
| v1.0 | AI 教练、比赛配速策略、应用商店发布 | 上架 |

## 2. 生产化迁移指引（v0.4）

- HTTP 层：`lib/http.js` 接口对齐 Express（req/res/next），路由表平移
- DB：`db/connection.js` 换 `pg` 驱动，迁移脚本沿用版本号；字段已是 ANSI 子集
- 密码哈希换 bcrypt/argon2；JWT 换 `jose`；加密密钥接入 KMS
- 同步任务改 BullMQ 队列 + 定时调度（当前为请求内同步执行）

## 3. 安全清单

- [x] 密码 PBKDF2-HMAC-SHA256（生产升级 bcrypt）
- [x] JWT HS256 + 短时效 access + 旋转 refresh
- [x] 第三方令牌 AES-256-GCM 加密，密钥环境变量
- [x] 全接口参数校验 + 统一错误码，不泄露内部堆栈
- [x] SQL 全参数化，无拼接
- [ ] 速率限制（v0.4 网关层）
- [ ] HTTPS 终结于反向代理（部署文档）

## 4. 隐私合规（个保法/GDPR 对齐）

- 健康数据明示授权收集；第三方授权页说明数据用途
- 支持导出个人数据（v0.3）与注销删除（v0.3）
- 服务端日志不落心率等敏感明细；同步审计仅计数

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 高驰/佳明企业资质审批周期长 | Mock + 文件导入兜底，核心体验不依赖审批 |
| Flutter 本机无 SDK 无法编译验证 | 代码评审 + 静态结构检查；README 给出 `flutter doctor` 构建步骤 |
| 计划算法科学性质疑 | 参数全部可追溯（params_json），配速表标注 Daniels 出处 |
