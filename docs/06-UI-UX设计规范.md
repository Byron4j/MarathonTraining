# UI/UX 设计规范

## 1. 设计原则

**科学感 × 运动感**：数据清晰克制、深色运动美学、关键指标一屏即达。Material 3 为基座。

## 2. 视觉系统

| 项 | 规范 |
|---|---|
| 主色 | 电光青 `#00D9A6`（活力/成绩），深色底上高对比 |
| 辅色 | 能量橙 `#FF6B35`（强度/警示）、心率红 `#FF4757` |
| 中性 | 深空灰阶 `#0E1116 → #1C2128 → #2D333B`（深色优先，浅色全套） |
| 字阶 | Display 32 / Title 20 / Body 15 / Caption 12；数字用等宽 tabular figures |
| 圆角 | 卡片 16、按钮 12、胶囊 999 |
| 区间色带 | Z1 蓝绿 `#4ECDC4` Z2 绿 `#95E06C` Z3 黄 `#FFD93D` Z4 橙 `#FF9F45` Z5 红 `#FF4757` |

## 3. 响应式断点（自适应核心）

| 断点 | 宽度 | 形态 | 导航 |
|---|---|---|---|
| compact | < 600dp | 手机/折叠态 | NavigationBar（底部 4 tab） |
| medium | 600–1024 | 竖平板/展开态 | NavigationRail + 内容单栏加宽 |
| expanded | > 1024 | 横平板/桌面 | 侧边 Drawer + 双栏（列表 360dp + 详情弹性） |

- 全部页面 `LayoutBuilder` 驱动；列表/详情在 expanded 下同屏双栏
- 卡片栅格：compact 1 列 / medium 2 列 / expanded 3 列

## 4. 信息架构（4 个一级入口）

```
仪表盘 Home ｜ 训练计划 Plan ｜ 活动 Activities ｜ 我的 Me
├─ 仪表盘：本周跑量卡、负荷趋势图(ATL/CTL/TSB)、今日课表卡、最近活动
├─ 计划：进行中计划卡 → 周视图（阶段色带+跑量柱）→ 课表详情（配速区间条）
├─ 活动：筛选列表 → 详情（地图预留位、配速/心率曲线、圈速表）
└─ 我的：档案、心率区间、数据连接(高驰/导入/Mock)、同步记录、设置
```

## 5. 关键页面体验

- **计划生成向导**：3 步（目标距离 → 目标成绩/日期 → 每周次数）+ 实时 VDOT/配速区预览，生成前可回看调整
- **课表卡片**：课型徽章（E/M/T/I/R/L 配色）+ 配速区间渐变条 + 心率区间色带 + 一键标记完成
- **空态/降级**：无数据时引导 Mock 体验或导入文件；高驰未配置时连接页显示「待申请企业开发者」说明卡
- **反馈**：同步/生成均骨架屏；成功触觉反馈；错误 Snackbar 带重试动作
- **无障碍**：对比度 ≥ 4.5:1；全部交互 ≥ 48dp；语义标签覆盖图表

## 6. 文案语言

默认简体中文，文案模板集中预留国际化。
