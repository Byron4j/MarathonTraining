# 马拉松训练 App — 产品需求文档（PRD）

> 版本：v1.0 ｜ 状态：已确认 ｜ 代号：**PaceForge**

## 1. 产品定位

面向严肃跑者的一站式马拉松训练平台：汇聚多平台（高驰 COROS / 佳明 Garmin / 华为 Huawei）运动数据，基于训练数据智能生成个性化训练计划，覆盖 5km / 10km / 半程马拉松 / 全程马拉松目标。

**核心价值**：数据集中管理 + 科学计划生成 + 训练执行闭环。

## 2. 目标用户

| 用户分层 | 特征 | 核心诉求 |
|---|---|---|
| 入门跑者 | 5K/10K 目标，跑量 < 30km/周 | 循序渐进的计划、防受伤 |
| 进阶跑者 | 半马/全马目标，有规律训练 | 成绩突破（PB）、周期化训练 |
| 严肃跑者 | 全马破四/破三，多平台数据 | 精细化数据分析、负荷管理 |

## 3. 功能需求（MoSCoW 优先级）

### 3.1 Must（本期实现）

**F1 账号与个人信息维护**
- 注册/登录（邮箱 + 密码，JWT 会话）
- 个人档案：昵称、性别、出生日期、身高、体重、静息心率、最大心率
- 跑步能力档案：各距离 PB（5K/10K/半马/全马）、当前周跑量、训练年限
- 心率区间设置（自动按储备心率法计算，可手动微调）

**F2 数据同步**
- 统一运动数据模型（活动 / 轨迹 / 圈数据 / 心率流）
- 数据接入框架（Provider 插件式架构）：
  - **高驰 COROS**：账号 OAuth2 授权接入（官方开放平台 open.coros.com）
  - **文件导入**：GPX 文件手动导入（佳明/华为/高驰均可导出）
  - **模拟数据**：内置 Mock Provider，便于无设备体验与开发调试
- 同步状态管理：增量同步、冲突去重、失败重试
- 手动录入：无设备跑步记录手动添加

**F3 智能训练计划**
- 目标模式：5km / 10km / 半马 / 全马
- 输入：目标日期或周期长度、目标成绩（可选）、每周可训练次数（3–7 次）、当前能力（自动从数据推断，可手动指定）
- 生成：周期化计划（基础期 → 进展期 → 巅峰期 → 减量期），逐周逐课表
- 课表类型：轻松跑(E)、马拉松配速跑(M)、乳酸门槛跑(T)、间歇跑(I)、重复跑(R)、长距离(L)、恢复跑、力量/交叉、休息
- 配速/心率区间自动计算（基于 VDOT 能力值）
- 计划自适应：根据近期完成度与负荷，提示调整建议

**F4 训练数据看板**
- 首页仪表盘：本周跑量、计划完成度、当前负荷（ATL/CTL/TSB 趋势）
- 活动列表与详情：距离/配速/心率/步频/爬升，配速与心率曲线
- 统计：周/月跑量柱状图、配速分布、心率区间分布

### 3.2 Should（架构预留，下一迭代）

- 佳明 Garmin（Health API / FIT SDK）、华为运动健康（Health Kit）官方 API 接入
- 训练计划推送到手表 / 日历订阅（ICS 导出）
- 跑鞋管理与里程追踪
- 社区/打卡分享

### 3.3 Could（远期）

- AI 教练对话、比赛日配速策略、营养补给建议、伤病预警

## 4. 非功能需求

| 维度 | 要求 |
|---|---|
| 多端自适应 | Flutter 一套代码适配 iOS / Android 手机、平板、折叠屏；响应式布局（紧凑/中等/宽三档断点） |
| 性能 | 列表滚动 60fps；活动详情页打开 < 500ms；同步在后台执行不阻塞 UI |
| 离线 | 核心数据本地缓存（SQLite），离线可浏览计划与历史 |
| 安全 | 密码 PBKDF2 哈希（生产升级 bcrypt）；JWT + Refresh Token；第三方授权令牌 AES-256-GCM 加密存储 |
| 隐私 | 健康数据属敏感数据；最小化收集；支持账号注销与数据删除（GDPR/个保法） |
| 可观测 | 服务端结构化日志；同步任务有审计记录 |

## 5. 范围外（本期不做）

- 实时 GPS 跑步记录（手表已是记录端，App 做管理端）
- 社交关系链、IM
- 电商/付费体系

## 6. 验收标准（MVP）

1. 可注册登录并维护完整个人档案
2. 可通过 Mock Provider / GPX 文件导入活动，列表与详情正确展示
3. 高驰授权链路代码完整（沙箱凭据可配），凭据缺失时优雅降级
4. 选择目标（如全马 4:00、18 周、每周 4 练）可生成完整逐日课表，配速区间合理
5. 仪表盘正确展示周跑量与负荷趋势
6. 后端 API 全部通过自动化冒烟测试
