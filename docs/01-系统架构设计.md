# 系统架构设计

## 1. 总体架构

```
┌─────────────────────────────────────────────┐
│            Flutter 客户端 (app/)             │
│  iOS / Android / 平板 / 折叠屏（自适应布局）  │
│  表现层 UI → 状态管理 → Repository → 本地缓存 │
└──────────────────┬──────────────────────────┘
                   │ HTTPS / JSON (REST)
┌──────────────────▼──────────────────────────┐
│          Node.js 后端 (server/)              │
│  ┌────────────┬─────────────┬─────────────┐ │
│  │ Auth 模块   │ 档案模块     │ 活动模块     │ │
│  ├────────────┼─────────────┼─────────────┤ │
│  │ 同步引擎    │ 计划引擎     │ 统计模块     │ │
│  │ (Provider  │ (VDOT/周期化)│             │ │
│  │  插件架构)  │             │             │ │
│  └────────────┴─────────────┴─────────────┘ │
│  SQLite（node:sqlite，零依赖，可换 PostgreSQL）│
└──────────────────┬──────────────────────────┘

        ┌──────────┼──────────┐
        ▼          ▼          ▼
    高驰 COROS  佳明 Garmin  华为 Huawei
   (本期实现)   (文件导入)   (文件导入)
```

## 2. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 客户端 | Flutter 3.x (Dart) | 一套代码多端，自适应布局能力强，原生性能 |
| 客户端状态 | Provider + ChangeNotifier | 简单可靠，团队门槛低 |
| 网络 | dio | 拦截器/重试/取消支持完善 |
| 本地缓存 | sqflite / shared_preferences | 结构化 + KV 分层缓存 |
| 图表 | fl_chart | 配速/心率曲线、跑量柱状图 |
| 后端 | Node.js + 零依赖（node:http + node:sqlite） | 立即可运行、无供应链风险；接口层与框架解耦，可平滑迁移 Express/Fastify + PostgreSQL |
| 认证 | JWT(HS256, 自实现) + PBKDF2(crypto) | 零依赖实现，算法标准 |
| 密钥存储 | AES-256-GCM（crypto）加密第三方令牌 | 敏感凭据不落明文 |

> **零依赖决策说明**：为保证任何环境 `node server/src/index.js` 即可运行、可测试，后端不依赖 npm 包。路由/中间件/JWT/哈希均以 Node 标准库实现（< 400 行基础设施代码）。生产化时按 `docs/07-路线图与安全.md` 迁移。

## 5. 关键设计

### 5.1 同步引擎（插件式）

```text
interface Provider {
  key: 'coros' | 'mock' | 'file' | 'garmin' | 'huawei'
  connect(account)      // OAuth 授权 / 凭据校验
  fetchSince(cursor)    // 增量拉取 → 统一活动模型
  normalize(raw)        // 平台原始数据 → UnifiedActivity
}
```
- 每个用户每平台一条 `sync_connection`（令牌加密存储 + 同步游标）
- 去重键：`provider + external_id` 唯一约束；文件导入用 `开始时间+距离+时长` 指纹
- 同步任务写入 `sync_job` 审计表（开始/结束/新增/跳过/错误）

### 5.2 计划引擎（纯函数，可独立测试）

输入：`{ raceType, goalTimeSec?, raceDate|weeks, sessionsPerWeek, vdot 或 pb }`
输出：逐周逐日课表（日期、课型、距离/时长、配速区间、心率区间、说明）
算法详见 `04-训练计划算法.md`。引擎无副作用，前后端共用同一套参数定义。

### 5.3 自适应 UI

- 断点：宽 < 600 紧凑（底部导航）；600–1024 中等（NavigationRail）；> 1024 宽（侧边栏 + 双栏内容）
- 平板/宽屏下：活动列表 + 详情双栏；计划页日历 + 详情双栏
- 全部页面使用 `LayoutBuilder` + 语义化栅格，不写死尺寸

### 5.4 错误与降级

- 第三方凭据缺失 → Provider 标记 `unavailable`，UI 引导配置，不阻塞其它功能
- 网络失败 → 本地缓存兜底展示 + 离线标识 + 自动重试（指数退避）

## 6. 部署形态

- 开发：`node server/src/index.js`（默认 :8080，SQLite 文件 `server/data/app.db`）+ `flutter run`
- 生产：后端 Docker 单容器起步；客户端走应用商店/内测分发（详见路线图）
