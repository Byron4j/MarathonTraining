# 数据模型设计

统一活动模型以「高驰/佳明/华为字段并集 + 训练分析所需字段」设计。SQLite 实现，字段命名 snake_case。

## ER 概览

```
users 1─1 profiles
users 1─n activities 1─n activity_streams / activity_laps
users 1─n sync_connections 1─n sync_jobs
users 1─n training_plans 1─n plan_workouts
```

## 表结构

### users
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | uuid |
| email | TEXT UNIQUE NOT NULL | 登录邮箱（小写） |
| password_hash | TEXT NOT NULL | pbkdf2$iterations$salt$hash |
| refresh_token_hash | TEXT | 当前刷新令牌哈希（单设备简化版） |
| created_at / updated_at | INTEGER | epoch ms |

### profiles
| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | TEXT PK FK | |
| nickname / gender / birth_date | | 基础信息 |
| height_cm / weight_kg | REAL | |
| resting_hr / max_hr | INTEGER | 心率基础 |
| pb_5k_sec / pb_10k_sec / pb_half_sec / pb_full_sec | INTEGER NULL | 各距离 PB（秒） |
| weekly_km / years_running | REAL | 当前周跑量、跑龄 |
| hr_zones_json | TEXT | 心率区间缓存（自动计算可覆盖） |

### activities（统一活动模型）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | TEXT PK | uuid |
| user_id | FK | |
| provider | TEXT | manual / mock / coros / file-gpx … |
| external_id | TEXT | 平台侧 ID；UNIQUE(user_id, provider, external_id) |
| sport | TEXT | run / trail_run / treadmill … |
| start_time | INTEGER | epoch ms（UTC） |
| duration_sec | INTEGER | 移动时长 |
| distance_m | REAL | |
| elevation_gain_m | REAL | |
| avg_pace_sec_per_km | INTEGER | 冗余便于列表 |
| avg_hr / max_hr | INTEGER | |
| avg_cadence | INTEGER | 步频 spm |
| calories | INTEGER | |
| training_effect | REAL | 训练效果（平台提供时） |
| source_file | TEXT | 导入文件名 |
| raw_json | TEXT | 平台原始数据（可选保留） |
| created_at | INTEGER | |

索引：`(user_id, start_time DESC)`、唯一 `(user_id, provider, external_id)`

### activity_streams（时间序列，按需）
| activity_id PK FK | sample_sec, hr_json, pace_json, cadence_json, alt_json（JSON 数组） |

### activity_laps
| activity_id FK | lap_no, distance_m, duration_sec, avg_hr, avg_pace |

### sync_connections
| 字段 | 说明 |
|---|---|
| id / user_id / provider | UNIQUE(user_id, provider) |
| status | connected / unavailable / error / revoked |
| access_token_enc / refresh_token_enc / token_expires_at | AES-256-GCM 密文 |
| external_user_id / scopes | 平台用户标识 |
| cursor | 增量同步游标（last_start_time 或平台 syncKey） |
| last_sync_at / last_error | |

### sync_jobs
| id / connection_id / started_at / finished_at / status | added / skipped / error_msg |

### training_plans
| 字段 | 说明 |
|---|---|
| id / user_id / name | |
| race_type | 5k / 10k / half / full |
| goal_time_sec | NULL 表示完赛目标 |
| race_date / start_date / weeks | |
| sessions_per_week | 3–7 |
| vdot | 生成时能力值快照 |
| status | active / completed / archived |
| params_json | 全部生成参数（可追溯） |

### plan_workouts
| plan_id FK / date / week_no / day_of_week / order_in_day |
| workout_type | E M T I R L RECOVERY XT REST RACE |
| title / description |
| target_distance_m / target_duration_sec |
| pace_min_sec / pace_max_sec | 目标配速区间（秒/km） |
| hr_zone | 1–5 |
| status | pending / done / missed / skipped |
| activity_id | 完成后关联活动 |

## 迁移策略

`db/migrations.js` 内含有序迁移数组 `{version, up(db)}`，启动时按 `PRAGMA user_version` 增量执行。生产换 PostgreSQL 时仅需重写 connection 层，SQL 保持 ANSI 子集。
