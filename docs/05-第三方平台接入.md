# 第三方平台接入指南

接入统一走 `server/src/modules/sync/providers/` 插件架构，新增平台只需实现 Provider 接口并注册。

## 1. 高驰 COROS（本期实现）

- 开放平台：https://open.coros.com （需申请企业开发者，获取 `client_id` / `client_secret`）
- 协议：OAuth2 授权码模式

### 授权流程

```
App → GET /sync/connections/coros/authorize-url
    → 后端返回 https://open.coros.com/oauth2/authorize?client_id=..&redirect_uri=..&state=..
App 打开系统浏览器授权 → COROS 回调 GET /sync/callback/coros?code&state
    → 后端 POST https://open.coros.com/oauth2/accesstoken 换 token
    → AES 加密存入 sync_connections → 重定向 paceforge://sync/success
```

### 数据拉取

| 端点 | 用途 |
|---|---|
| POST open.coros.com/v2/coros/sport/list | 增量拉取运动列表（按时间/labelId 游标） |
| POST open.coros.com/v2/coros/sport/detail | 单条详情（含心率流/FIT 下载地址） |

字段映射：distance(m)→distance_m、duration→duration_sec、avgHeartRate→avg_hr、avgSpeed→配速换算、stepFrequency→avg_cadence。

### 凭据配置（环境变量）

```
COROS_CLIENT_ID=xxx
COROS_CLIENT_SECRET=xxx
COROS_REDIRECT_URI=http://localhost:8080/api/v1/sync/callback/coros
COROS_API_BASE=https://open.coros.com
TOKEN_SECRET=<32字节随机，用于 AES 加密令牌>
```
凭据缺失 → Provider 状态 `unavailable`，接口正常返回说明，不阻塞 mock/文件导入。

## 2. 文件导入（佳明/华为/高驰通用，本期实现 GPX）

- 佳明：Garmin Connect 网页版 → 活动 → 导出 GPX/TCX/FIT
- 华为：运动健康 → 我的 → 隐私管理 → 数据导出（GPX）
- 高驰：COROS App → 活动 → 导出

App 内「导入」选择文件 → `POST /activities/import`（Base64）→ 解析 trkpt（time/lat/lon/ele/hr）→ 计算距离（Haversine）/时长/配速 → 指纹去重入库。
FIT/TCX 解析在下一迭代加入（FIT 建议用官方 SDK 预转 GPX）。

## 3. 佳明 Garmin（下一迭代）

- 备选：Garmin Connect Developer Program / FIT SDK 直连设备
- 预留 Provider 键 `garmin`，模型字段已兼容（training_effect、lactate 等）

## 4. 华为 Huawei（下一迭代）

- 华为运动健康服务（Health Kit / 云端 REST）：OAuth2 + HMS 生态，国内合规优势
- 预留 Provider 键 `huawei`

## 5. Mock Provider（本期实现）

- 一键生成近 8 周拟真训练数据（每周 3–5 次，配速/心率围绕用户 VDOT 波动）
- 用于：无设备体验、开发调试、自动化测试种子数据

## 6. 合规与安全要点

- 令牌 AES-256-GCM 加密存储，密钥仅环境变量；日志脱敏
- 用户可一键断开连接并删除平台授权（同时调平台 revoke 端点，如有）
- 健康数据导出/删除能力随账号注销提供（PRD 非功能需求）
