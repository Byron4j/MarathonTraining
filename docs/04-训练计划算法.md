# 训练计划算法

基于 **Jack Daniels VDOT 体系** + 经典周期化理论，输出可执行逐日课表。引擎为纯函数，位于 `server/src/modules/plans/engine.js`。

## 1. 能力评估：VDOT

由任一 PB 成绩反推 VDOT（Daniels 公式）：

```
VDOT = VO2 / %VO2max
VO2  = -4.60 + 0.182258·v + 0.000104·v²        (v = 速度 m/min)
%VO2max = 0.8 + 0.1894393·e^(-0.012778·t) + 0.2989558·e^(-0.1932605·t)   (t = 分钟)
```

- 取用户各 PB 中 VDOT 最高者；无 PB 时用近期轻松跑配速+心率保守估计（下限 30）
- 目标成绩合法性校验：目标 VDOT 较当前 VDOT 提升 > 4 且周期 < 16 周 → 提示激进

## 2. 训练配速区间（秒/公里，随 VDOT 插值）

| 课型 | 强度基准 | 典型区间（VDOT 40→50 示例） |
|---|---|---|
| E 轻松跑 | 59–74% VO2max | 5:59–5:12 → 5:07–4:29 |
| M 马拉松配速 | 75–84% | 5:12–4:51 → 4:29–4:11 |
| T 乳酸门槛 | 83–88% | 4:46–4:32 → 4:05–3:54 |
| I 间歇 | 97–100% | 4:24 → 3:53（/km 等效） |
| R 重复跑 | 105–120% | 200m 48s → 41s |

实现：内置 Daniels 经典 VDOT 30–60 配速表（E/M/T/I/R 配速），VDOT 中间值线性插值，心率区间与配速区间双锚定输出。

## 3. 心率区间（储备心率法 Karvonen）

```
HRR = maxHR − restingHR
Zone i 范围 = restingHR + HRR × [低%, 高%]
Z1 50–60% | Z2 60–70% | Z3 70–80% | Z4 80–90% | Z5 90–100%
```
课型映射：E→Z2、M→Z3、T→Z4、I/R→Z5、恢复→Z1。

## 4. 周期化结构

| 阶段 | 占比（18周例） | 目的 |
|---|---|---|
| 基础期 Base | ~35% | 有氧基础，E 为主 + 少量 T |
| 进展期 Build | ~30% | 加入 M/T 质量课，I 刺激 |
| 巅峰期 Peak | ~20% | 专项强度最大，长距离含 M 段落 |
| 减量期 Taper | ~15%（全马 2–3 周） | 降量保强度，比赛日收尾 |

周跑量曲线：`起始量 = max(当前周跑量, 距离下限)`，每周 +5–8%，每 4 周一个减量周（−25%）；峰值周跑量按目标距离封顶（5K 35km / 10K 50km / 半马 65km / 全马 90km，且随 VDOT 缩放）。

## 5. 周内课表模板（按训练次数）

以全马、每周 4 练为例（周二/四/六/日）：

| 日 | 课型 |
|---|---|
| 二 | 质量课1：T 节奏跑 或 I 间歇（按阶段轮换） |
| 四 | E 轻松跑 + 短加速跑 |
| 六 | M 配速跑 或 中距离 E |
| 日 | L 长距离（峰值周含 M 配速段） |

3 练：质量课 + E + L；5–6 练：在上述基础上插入恢复跑/XT；7 练不建议（给出提示）。
课次时长上限：质量课 ≤ 周跑量 25%，L ≤ 35%（全马 L 上限 32–35km 或 150min 先到为准）。

## 6. 课表生成流程

```
1. resolveVdot(input)            → 能力值
2. buildWeekCurve(weeks, type)   → 每周目标跑量 + 阶段标签
3. for each week:
     pickTemplate(sessions)      → 课型骨架
     assignQuality(phase)        → 质量课具体化（T/I 轮换、M 配比）
     splitVolume(weekKm)         → 各课次距离
     paceRange(vdot, type)       → 配速/心率区间
4. 末周嵌入 RACE 课（比赛日）
```

## 7. 计划自适应（/plans/:id/adapt）

- 统计近 2 周完成率 `done/(done+missed)`
- 完成率 ≥ 85%：维持；60–85%：下周跑量 −10%；< 60%：降一级质量课强度并 −15% 量
- 若用户录入新 PB → 提示重估 VDOT，一键重算后续课表

## 8. 负荷模型（统计模块）

```
ATL(疲劳) = 近 7 天 TRIMP 指数均值；CTL(体能) = 近 42 天指数加权
TSB(状态) = CTL − ATL；TRIMP ≈ duration(min) × HR储备比 × 性别系数
```
用于仪表盘趋势展示与减量效果可视化。
